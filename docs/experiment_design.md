# 实验设计文档

> 本文描述的是**模拟实验**的设计。真实实验落地时还需要实验平台、埋点校验、灰度发布与法务/隐私审查。

## 1. 目标与假设

| 项 | 内容 |
| --- | --- |
| 业务问题 | 营销触达能否提升用户转化与人均 GMV？哪些用户值得优先触达？ |
| H0 | 实验组与对照组的转化率相同（Δ = 0） |
| H1 | 实验组转化率更高（双侧检验用于报告，方向性结论依赖点估计与 CI） |
| 决策规则 | 若 95% CI 下界 > 0 且 SRM/平衡检查通过，则判定"有效"；增量模型只用于排序，不用于判定实验成败 |

## 2. 实验单位与分流

- **单位**：`user_id`。一个用户只会进入一个组，避免同一用户跨组污染。
- **分流比**：50% / 50%，独立随机。
- **分流校验**：卡方拟合优度检验，`p < 0.001` 视为 SRM（sample ratio mismatch）。阈值取 0.001 而不是 0.05，
  因为 SRM 检查是"护栏"而不是待检验的科研假设，过低的阈值会频繁误报。
- **为什么先查 SRM**：分流坏掉时，两组不可比，后续任何显著性都不可信；此时应停止分析、排查埋点或分流逻辑。

## 3. 指标定义

| 指标 | 定义 | 类型 | 检验 |
| --- | --- | --- | --- |
| 转化率 | 转化用户数 ÷ 组内用户数 | 二值比例 | 两比例 z 检验 + 分层 Bootstrap |
| 人均 GMV | 组内 GMV 总和 ÷ 组内用户数（未转化记 0） | 连续、零膨胀 | Welch t 检验 + 分层 Bootstrap |

- 人均 GMV 的分母是**组内全部用户**，不是转化用户，否则会把"转化率提升"和"客单价提升"混在一起。
- 两个指标同时检验，使用 Holm-Bonferroni 控制族错误率。

## 4. 样本量与最小可检测效应

给定基线转化率 `p`、每组样本量 `n`、显著性 `α`、功效 `1-β`：

```
MDE = (z_{1-α/2} + z_{1-β}) * sqrt(2 p (1-p) / n)
```

本次模拟：p ≈ 7.25%、n ≈ 30,000/组 → MDE ≈ 0.59 pp。
真实 ATE 设为 3.98 pp，远大于 MDE，因此实验有足够功效检测到该效应。

**反推样本量**：若目标 MDE = 1 pp，p = 7%，则 n ≈ 2 * 0.07 * 0.93 * (1.96+0.84)² / 0.01² ≈ 11,400/组。
真实业务中应先用历史数据估计 p，再决定样本量与实验周期。

## 5. 协变量与平衡

- 纳入平衡检查的协变量必须是**实验前**可观测的：历史订单数、最近购买间隔、注册时长、渠道、设备。
- 平衡指标使用标准化均值差 `SMD = (mean_t - mean_c) / sqrt((var_t + var_c)/2)`，类别变量按水平比较比例。
- 判定阈值：`|SMD| < 0.1`。比 p 值更稳健（p 值随样本量增大必然显著）。

## 6. 模拟器的真实机制

- 基线转化：`sigmoid(-2.1 + 0.25*prior_orders - 0.005*recency + channel_effect + device_effect)`。
- 个体增量 `tau(x)`：0 单 ≈ 0.5%、1 单 ≈ 3%、2-3 单 ≈ 6.5%、4+ 单 ≈ 9.5%，email 渠道 +3%，mobile +1%，
  超过 180 天未购买 −1%，截断在 [0.2%, 14%]。
- 收益：仅转化者产生，log-normal(mean=log(80)+0.18*prior_orders, sigma=0.65)。
- 因此真实 ATE 可由 `mean(p1 - p0)` 精确计算，用于校验估计值（本次 3.98 pp vs 估计 3.96 pp）。

## 7. 威胁与应对

| 威胁 | 表现 | 应对 |
| --- | --- | --- |
| SRM | 分流比偏离 50/50 | 卡方检验，p<0.001 直接中止 |
| 协变量不平衡 | 某特征 SMD ≥ 0.1 | 报告并中止；真实场景需分层/回归调整 |
| 新奇效应 | 实验初期效果虚高 | 延长观察窗、分段看时间趋势（本项目未模拟） |
| 干扰/溢出 | 用户间互相影响 | 按地理/社交簇分流（本项目未模拟） |
| 多重比较 | 多指标假阳性 | Holm 校正 |
| Peeking | 多次查看导致假阳性 | 固定样本量或 alpha spending（本项目未实现） |
| 结果泄漏 | 用处理后变量做特征 | 特征白名单 + 测试断言 |
