# 方法说明：统计检验与增量模型

## 1. 两比例 z 检验（转化率）

设实验组 `x_t / n_t`、对照组 `x_c / n_c`：

```
p_t = x_t / n_t,  p_c = x_c / n_c
diff = p_t - p_c
SE   = sqrt(p_t(1-p_t)/n_t + p_c(1-p_c)/n_c)
z    = diff / SE
p    = 2 * (1 - Φ(|z|))
CI   = diff ± z_{1-α/2} * SE
```

- 使用**非合并**标准误（两臂方差可能不同），与 Welch 的思路一致。
- 正态近似要求每臂期望成功/失败数 ≥ 5；本数据 n≈30,000、p≈7%，满足。
- 代码：`src/abtest/stats.py::two_proportion_ztest`。

## 2. Welch t 检验（人均 GMV）

不假设两臂方差相等，自由度用 Welch–Satterthwaite 近似：

```
t = (mean_t - mean_c) / sqrt(s_t²/n_t + s_c²/n_c)
```

适合零膨胀、右偏的收益指标（大量 0 + 少量大额）。

- 代码：`src/abtest/stats.py::welch_ttest`。

## 3. 分层 Bootstrap

- 在每个实验臂内部有放回重采样（保持臂样本量不变），重复 2000 次；
- 得到差值分布，取 2.5% / 97.5% 分位作为 95% CI；
- p 值 = 2 × min(差值 ≤ 0 的比例, 差值 ≥ 0 的比例)，若为 0 则报告 `1/(B+1)`，因为有限次重采样无法证明 p=0。

**为什么分层**：若整体重采样，每次重采样的分流比例会波动，把"臂间样本量变化"引入差值分布，
低估方差。分层重采样对应"固定设计"的随机化推断。

- 代码：`src/abtest/stats.py::bootstrap_difference`。

## 4. Holm-Bonferroni

对 m 个 p 值升序排列，第 k 小的 p 值乘以 `(m - k + 1)`，并保证调整后 p 值单调不减，最后截断到 1。
比 Bonferroni 保守度低，且控制族错误率（FWER）。

## 5. T-learner

分别用实验组和对照组数据拟合两个响应模型：

```
μ1(x) = P(Y=1 | X=x, T=1)
μ0(x) = P(Y=1 | X=x, T=0)
τ̂(x) = μ1(x) - μ0(x)
```

- 模型：梯度提升分类器（HistGradientBoosting，max_depth=3，200 轮）+ 标准化 + one-hot；
- 只使用实验前特征（白名单见 `config.FEATURE_COLUMNS`）；
- 训练/测试按用户切分；
- `τ̂(x)` 是**排序分数**，不是个体的真实因果效应。

**为什么用 T-learner**：实现简单、可解释（两个响应模型），在随机实验数据上不需要倾向得分；
局限是两模型各自误差会叠加，低样本段不稳定。

## 6. Qini 曲线与 AUUC

把测试集按预测增量降序排列，对前 k 个人：

```
Q(k) = Y_t(k) − Y_c(k) · N_t(k) / N_c(k)
```

- `Y_t(k)`、`Y_c(k)`：前 k 人中实验组/对照组的累计转化数；
- `N_t(k)`、`N_c(k)`：前 k 人中的累计组内人数；
- 该式把对照组缩放到实验组规模，得到"累计增量转化"；
- `Q(n)` 等于全样本的总增量（所有策略共用同一终点）。

**AUUC**：`Q(k)` 对累计人群占比的梯形积分（单位：转化数）。

**归一化**：随机排序的 Qini 在期望上是线性的（从 0 到 `Q(n)`），面积 = `0.5 · Q(n)`。
因此

```
normalised Qini = (area_model − 0.5·Q(n)) / (area_oracle − 0.5·Q(n))
```

1 = oracle 排序，0 = 随机触达，负数 = 比随机还差。

> 很多实现把 AUUC 除以 oracle 面积，导致"随机排序"也有 0.5 左右的分数，容易被误读为"模型不错"。
> 本项目显式使用随机基线，并在报告里写了定义。

- 代码：`src/abtest/uplift.py::qini_curve / qini_area / random_baseline_area / normalized_auuc`。

## 7. 十分位观测增量

按预测增量排序后切 10 等份，在每一份内分别计算实验组与对照组的转化率之差，并用正态近似给出 95% CI：

```
SE = sqrt(p_t(1-p_t)/n_t + p_c(1-p_c)/n_c)
```

十分位表回答的是"模型排序是否真的分出了高低增量"，比单看 AUUC 更直观，也更容易被业务方理解。

## 8. 方法边界

1. 增量模型依赖**随机化**：若数据来自观察性研究，必须改用倾向得分/双重稳健方法。
2. 只评估了排序质量，没有评估"按 uplift 投放"的长期收益（需考虑预算、成本、边际递减）。
3. 二值结果 + 有限测试集时，相邻十分位的 CI 会重叠，不能宣称"第 3 名一定比第 4 名好"。
4. 模拟器的效应是加性的；真实场景可能存在交互与非线性，模型需要重新验证。
